# เว็บเปิดหาร (Google Apps Script)

หน้าเว็บแสดงรายการของที่แต่ละคนมาหาร โดยดึงจาก Google Sheet ที่ใช้อยู่ได้เลย และ **แนบรูปให้แต่ละคนได้** (รูปเก็บใน Google Drive)

- แท็บตามชีต (เช่น `MHA`, `arknights`)
- แยกเป็นรอบหารตามคอลัมน์ K (เช่น Jump GIGA 2025, Bromide MHA JF2026, Snapmide 8)
- **รอบที่ของยังไม่ถึงมือขึ้นก่อนเสมอ** รอบที่ถึงมือแล้วจะไปอยู่ท้าย
- การ์ดของแต่ละคน: ของ, เจ้าของ, สถานะจ่าย, ส่งแบบ, ส่งแล้ว/ยัง, note, ช่องทางติดต่อ, โค้ดส่วนตัว, รูปที่แนบ
- สรุปต่อรอบ: กี่คน, ช่องว่าง, จ่ายครบ, ส่งแล้ว
- **หลักฐานการสั่ง** ต่อรอบหาร: สั่งที่ร้านไหน + ลิงก์ร้าน/ออเดอร์ + รูปหลักฐาน
- **ติดตามสถานะ** ต่อรอบหาร: 📝 สั่งแล้ว → ✈️ ของกำลังมา → 🛬 ถึงไทย → 📦 ถึงมือ พร้อมวันที่ของแต่ละขั้น
- ช่องค้นหา: พิมพ์ชื่อตัวเองหรือชื่อของ จะเห็นเฉพาะของตัวเอง
- **โหมดแอดมิน** (ใส่รหัส): แนบ/ลบรูป, ลบรูปทั้งหมดของรอบที่จบแล้ว (ประหยัดพื้นที่ Drive), แก้ร้าน/ลิงก์, แนบหลักฐาน, เปลี่ยนสถานะและวันที่, เห็นสลิป
  (คนทั่วไปเห็นทุกอย่าง ยกเว้นสลิป)

## ติดตั้ง

1. เปิด Google Sheet เปิดหาร > **ส่วนขยาย > Apps Script**
2. วางโค้ด `Code.gs` ทับไฟล์ `Code.gs` เดิม
3. กด **＋ > HTML** ตั้งชื่อ `Index` แล้ววางโค้ดจาก `Index.html`
4. (แนะนำ) การตั้งค่าโปรเจกต์ ⚙️ > ติ๊ก **"แสดงไฟล์ Manifest 'appsscript.json' ในเครื่องมือแก้ไข"** แล้ววางจาก `appsscript.json`
   ไฟล์นี้เปิด **Drive API** ไว้ให้ ทำให้ปุ่มลบรูป **ลบถาวรคืนพื้นที่ทันที**
   (ถ้าไม่ได้วาง รูปที่ลบจะไปอยู่ในถังขยะ Drive และถูกลบถาวรเองใน 30 วัน หรือไปกดล้างถังขยะเอง)
5. **ตั้งรหัสแอดมิน**: ใน `Code.gs` บรรทัดบนๆ แก้ `ADMIN_PIN: ''` เป็นรหัสที่ต้องการ (อย่างน้อย 4 ตัว)
   เช่น `ADMIN_PIN: '25690101',` แล้วกดบันทึก (คนเปิดเว็บมองไม่เห็นโค้ดนี้)
   - หรือรีเฟรชหน้าชีต แล้วใช้เมนู **เปิดหาร > ตั้งรหัสแอดมิน** แทนก็ได้ (เมนูจะขึ้นเฉพาะสคริปต์ที่สร้างจาก ส่วนขยาย > Apps Script ของชีตนั้น)
   - ชีตซ่อน `_Photos`, `_Orders` และโฟลเดอร์ `เปิดหาร - รูปภาพ` ใน Drive จะถูกสร้างให้เองตอนใช้งานครั้งแรก
6. ใน Apps Script กด **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
7. คัดลอกลิงก์เว็บแอปไปแชร์ (ดูอีกครั้งได้ที่เมนู เปิดหาร > ลิงก์หน้าเว็บ)

> แก้โค้ดแล้วต้อง **การทำให้ใช้งานได้ > จัดการ > แก้ไข > เวอร์ชันใหม่** ลิงก์เดิมถึงจะอัปเดต
> วางไฟล์ใหม่ทับเมื่อไหร่ อย่าลืมใส่ `ADMIN_PIN` กลับเข้าไป

## รูปแบบชีตที่รองรับ

ปรับเลขคอลัมน์ได้ที่ `CONFIG.COL` ใน `Code.gs`

| คอลัมน์ | ข้อมูล | คนทั่วไปเห็น |
|---|---|---|
| A | ของที่หาร (แถวที่เขียน `z` = แถวคั่นรอบ) | ✅ |
| B | เจ้าของ (ว่าง / `ว่าง` = ช่องยังว่าง) | ✅ |
| C | สถานะจ่าย | ✅ |
| D, E | ช่องทางติดต่อ / สำรอง | ✅ |
| F | ส่งแบบ | ✅ |
| G | สลิป (รูปในเซลล์ หรือข้อความ) | 🔒 เฉพาะแอดมิน |
| H | ส่ง | ✅ |
| I | note | ✅ (ปิดได้ `PUBLIC_NOTE: false`) |
| J | โค้ดส่วนตัว | ✅ |
| K | ชื่อรอบหาร (ผสานเซลล์คร่อมแถวของรอบนั้น) — ถ้าใส่เป็นลิงก์ จะนับเป็นลิงก์ของรอบที่อยู่ด้านบน | ✅ |
| L เป็นต้นไป | ข้อมูลรอบหาร: รูป → รูปของรอบ, ลิงก์ → ลิงก์ของรอบ, ข้อความ → รายละเอียดรอบ | ✅ |

- รอบหารนับต่อเนื่องลงไปจนกว่าจะเจอแถว `z` หรือชื่อรอบใหม่ในคอลัมน์ K
  ดังนั้นแถวที่เกินช่วงที่ผสานเซลล์ของ K ก็ยังอยู่รอบเดิม ไม่ต้องผสานเซลล์ใหม่ทุกครั้งที่เพิ่มคน
- แถวที่ชื่อของตรงกับชื่อรอบและไม่มีเจ้าของ (เช่น `SNAPMIDE 8`) ถือเป็นหัวข้อ ไม่นับเป็นคน
- ชีตที่ชื่อขึ้นต้นด้วย `_` หรือถูกซ่อนจะไม่แสดง (หรือกำหนดเองใน `CONFIG.SHEETS`)
- สีสถานะจ่าย: เรียบร้อย / ครบ / โอนเต็ม / โอนแล้ว = เขียว, มีคำว่า มัดจำ / เหลือ / ขาด = เหลือง, รอ... = ม่วง

## การแนบรูป

- กด 🔒 แอดมิน > ใส่รหัส > กด **＋ แนบรูป** ที่การ์ดของคนนั้น (เลือกได้หลายรูป) หรือ **＋ รูปรอบ** ที่หัวรอบหาร
- รูปจะถูกย่อเหลือด้านยาว 1600px ก่อนอัปโหลด แล้วเก็บในโฟลเดอร์ Drive (แชร์แบบ "ทุกคนที่มีลิงก์ดูได้" เพื่อให้แสดงบนเว็บ)
- รูปผูกกับแถวด้วย Developer Metadata — **แทรก/ลบ/เรียงแถวใหม่ในชีตได้ รูปยังอยู่กับคนเดิม**
- รายการรูปเก็บในชีตซ่อน `_Photos` (ห้ามแก้คอลัมน์ rowId)

## ลบรูปทั้งหมดของรอบ (ประหยัดพื้นที่ Drive)

- โหมดแอดมิน > ที่หัวรอบหารกด **🗑 ลบรูปทั้งหมดของรอบนี้ (N รูป)** (ปุ่มขึ้นเฉพาะรอบที่มีรูป)
- ลบทุกรูปของรอบนั้น: รูปรอบ, รูปหลักฐานการสั่ง และรูปที่แนบให้แต่ละคน
- ข้อความ (ร้าน, ลิงก์, สถานะ, วันที่) และข้อมูลในชีตหลัก **ไม่ถูกลบ** — ใช้พื้นที่น้อยมาก
- ถ้ารอบยังไม่ถึงขั้น "ถึงมือ" จะมีคำเตือนเพิ่มก่อนยืนยัน
- รูปที่ดึงมาจากชีต (รูปที่วางในคอลัมน์ทางขวาของ K) ไม่ได้อยู่ใน Drive ของเว็บนี้ จึงไม่ถูกลบ

## หลักฐานการสั่ง

- โหมดแอดมิน > ที่หัวรอบหารกด **✏️ แก้ไขร้าน/ลิงก์** ใส่ชื่อร้าน และลิงก์ (ร้าน / หน้าออเดอร์ / โพสต์) แล้วกดบันทึก
- กด **＋ หลักฐาน** เพื่อแนบรูป เช่น แคปหน้าคำสั่งซื้อ ใบเสร็จ อีเมลยืนยัน (หลายรูปได้)
- ข้อมูลร้าน/ลิงก์เก็บในชีตซ่อน `_Orders` (แก้ในชีตตรงๆ ก็ได้ ชื่อชีต + ชื่อรอบหารต้องตรงกับคอลัมน์ K)
- ถ้าเปลี่ยนชื่อรอบในคอลัมน์ K ต้องแก้ชื่อใน `_Orders` ด้วย ไม่งั้นข้อมูลร้านจะไม่ขึ้น

## ติดตามสถานะ

อยู่ใต้หลักฐานการสั่งของทุกรอบ ทุกคนเห็น (รอบที่ยังไม่ตั้งสถานะจะเป็นสีเทาทั้งแถบ) แอดมินกดเปลี่ยนได้

| ขั้น | ความหมาย |
|---|---|
| 1. 📝 สั่งแล้ว | ฝากร้านกด หรือสั่งเอง |
| 2. ✈️ ของกำลังมา | |
| 3. 🛬 ถึงไทย | ถึงไทยแล้ว รอทางร้านจัดส่งมาหา |
| 4. 📦 ถึงมือ | ของพร้อมส่ง |

- โหมดแอดมิน: กดวงกลมขั้นไหน สถานะจะเป็นขั้นนั้น (ขั้นก่อนหน้าติ๊กให้อัตโนมัติ) กดขั้นปัจจุบันซ้ำ = ถอยกลับ 1 ขั้น
- ระบบจดวันที่ที่ถึงแต่ละขั้นไว้ให้ ถ้าไม่ใช่วันจริง (ลืมกด / สั่งไว้นานแล้ว) แอดมินกดที่วันที่ใต้ขั้นนั้นแล้วเลือกวันใหม่ได้
  (เก็บในชีตซ่อน `_Orders` คอลัมน์ F–J แก้ในชีตตรงๆ ก็ได้)
- รอบที่ถึงมือแล้ว (ขั้น 4) จะถูกย้ายไปไว้ท้ายหน้า

## ข้อจำกัด

- รูปลอยที่วางทับชีต (คอลัมน์ทางขวาของ K) **มักแสดงบนเว็บไม่ได้** เพราะ Google ไม่ให้เปิดรูปนั้นนอกชีต
  เว็บจะซ่อนรูปที่เปิดไม่ได้ให้เอง วิธีให้มีรูปปก:
  1. (แนะนำ) โหมดแอดมิน > กด **＋ รูปรอบ** แล้วอัปโหลดรูปเดียวกัน — ขึ้นแน่นอน
  2. หรือในชีต คลิกรูป > เมนู ⋮ ของรูป > **วางรูปภาพในเซลล์ที่เลือก** (Place image in selected cell) — อาจขึ้น แต่ไม่รับประกัน
- บัญชี Google Workspace บางองค์กรห้ามแชร์ไฟล์แบบลิงก์ รูปจะไม่แสดงกับคนนอก
- ใส่รหัสแอดมินผิดเกิน 10 ครั้ง จะล็อก 15 นาที
